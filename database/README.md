# Database Design · Lia

Modelo de dados da Lia no Oracle SQL Developer Data Modeler: 10 entidades (usuário, familiar, ponto de atendimento, serviço, pedido, documento, confirmação, análise de golpe, consentimento e progresso), com os mesmos nomes do núcleo em Java.

- [AuxiLia_Database_Design.pdf](AuxiLia_Database_Design.pdf): descritivo, entidades, atributos, relacionamentos, cardinalidades e os modelos conceitual e lógico.
- [AuxiLia_Modelo_Oracle.sql](AuxiLia_Modelo_Oracle.sql): o modelo em SQL. No Data Modeler: File > Import > DDL File (Oracle 12c ou mais novo).

Nenhum dado pessoal real: o usuário é pseudonimizado, e o banco não guarda telefone nem foto.
