# Personas

Construídas a partir da entrevista com a dona Rosária (13/11/2026, gravada pelo Vinicius) e de dados públicos (IBGE, Inaf e Cetic.br). Onde não houve entrevista, a persona está marcada como **hipótese**, para validar no piloto.

## 1. Dona Rosária, quem usa a Lia
*Base: entrevista real.*

| | |
| --- | --- |
| **Quem é** | 57 anos, diarista. Mora perto da nora. Usa o celular para conversar com a família |
| **Como resolve hoje** | Pede para a nora, o marido ou os filhos. "Eu não consigo. Eu tenho que pedir pra alguém fazer." |
| **Dores** | Esperar alguém ter tempo ("tem que esperar a boa vontade deles"); ficar chateada por não saber; não saber se uma mensagem é golpe (manda para a nora conferir); não conseguir resolver coisas de banco |
| **O que quer aprender primeiro** | Mandar mensagem, pedir coisas e resolver o que hoje depende de ir ao banco |
| **O que a Lia precisa ser para ela** | Falar e ouvir, sem exigir leitura; mostrar onde tocar e deixar ela fazer; avisar quando for golpe; ajudar cada vez menos, até ela conseguir sozinha |

## 2. A nora, quem ajuda hoje
*Hipótese, a partir do relato da Rosária. Não foi entrevistada.*

| | |
| --- | --- |
| **Quem é** | Adulta, trabalha, mora perto da sogra e é a primeira a ser chamada |
| **Dores** | Ser interrompida várias vezes por coisas pequenas; conferir mensagens suspeitas; preocupação com golpes |
| **O que espera da Lia** | Configurar uma vez (contatos e permissões) e confiar que a sogra está segura; ser avisada só quando importa; ver que ela está aprendendo |
| **Como a Lia atende** | Ajustes para a família; recados com confirmação; a Lia pergunta se a pessoa quer contar o progresso para a família |

## 3. Atendente do CRAS Centro de Taiobeiras, quem pode levar a Lia
*Hipótese de parceiro para o piloto. Não foi entrevistada.*

| | |
| --- | --- |
| **Quem é** | Técnica de referência do CRAS (Rua Santos Dumont, 336, Centro) |
| **Dores** | Pessoas que chegam pedindo ajuda com serviços digitais (gov.br, CadÚnico, INSS) que poderiam fazer em casa |

## O que os dados dizem sobre esse público
- 3 em cada 10 brasileiros de 15 a 64 anos são analfabetos funcionais (Inaf 2024).
- 20,3% das pessoas com 65 anos ou mais são analfabetas (IBGE, Censo 2022).
- 37,8% das pessoas com 60 anos ou mais nunca usaram a internet (Cetic.br, TIC Domicílios 2025), por isso a Lia também atende por ligação.
